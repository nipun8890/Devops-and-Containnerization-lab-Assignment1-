Overview

This project demonstrates a containerized web application using FastAPI and PostgreSQL. Both services run in separate Docker containers and are orchestrated using Docker Compose. Networking is implemented using IPvlan with static IP assignment.

Project Architecture

Client → Backend (FastAPI) → PostgreSQL → Volume

Prerequisites

docker --version
docker compose version

Project Structure

backend/
database/
docker-compose.yml

Steps

Step 1

mkdir docker-webapp
cd docker-webapp

Step 2

mkdir backend
mkdir database

Step 3

docker network create -d ipvlan ...

Step 4

docker compose up --build
